# Perforation for MPC

**スマホから PC の MPC-HC / MPC-BE を操作するリモコン。**
A phone remote control for the MPC-HC / MPC-BE video players on your Windows PC.

## 日本語

Perforation for MPC は、PC の動画プレイヤー **MPC-HC / MPC-BE** を、同じ Wi-Fi 上のスマートフォンから操作するリモコンです。ソファやベッドから、再生・一時停止・シーク・音量・フォルダの動画選択まで手元で完結します。

### 使い方（3 ステップ）

1. **PC に MPC-HC または MPC-BE を入れる**
   - MPC-HC: https://github.com/clsid2/mpc-hc/releases
   - MPC-BE: https://sourceforge.net/projects/mpcbe/
2. **PC 用サーバーを起動する** — 下の「ダウンロード」から入手して実行するだけ
   （初回起動時に MPC の検出・設定を全自動で行い、タスクトレイに常駐します）
3. **スマホアプリで「PC を自動検索」** — 同じ Wi-Fi 上の PC を自動で見つけて接続

### ダウンロード

- **PC 用サーバー（Microsoft Store・推奨）**: [Microsoft Store で入手](https://apps.microsoft.com/detail/9NT52T3RHR46)
  — 署名済みなので SmartScreen の警告なしで入ります
- **PC 用サーバー（GitHub）**: [最新リリース](https://github.com/sui-notes/Perforation-for-MPC/releases/latest)
  - `Perforation-Server-Setup-vX.X.X.exe` … インストーラー版
  - `Perforation-Server-vX.X.X-portable.zip` … ポータブル版（解凍して実行）
- **Android アプリ**: [Google Play で入手](https://play.google.com/store/apps/details?id=jp.perforation)

### 動作環境

- Windows PC（MPC-HC または MPC-BE がインストール済み）
- Android スマートフォン
- スマホと PC が同じ Wi-Fi ネットワークに接続されていること

### 使い方ガイド・困ったときは

詳しい使い方とトラブルシューティング（PC が見つからない・チャプターが出ない等）は
**[使い方ガイド](https://sui-notes.github.io/Perforation-for-MPC/guide.html)** をご覧ください。

### プライバシー

このアプリは個人情報を収集・送信しません。詳細は [プライバシーポリシー](https://sui-notes.github.io/Perforation-for-MPC/privacy-policy.html) をご覧ください。

## English

Perforation for MPC turns your phone into a remote control for the **MPC-HC / MPC-BE** video players on your PC. Play, pause, seek, change the volume, and pick videos from your folders — all from the couch.

### Quick start (3 steps)

1. **Install MPC-HC or MPC-BE on your PC**
   - MPC-HC: https://github.com/clsid2/mpc-hc/releases
   - MPC-BE: https://sourceforge.net/projects/mpcbe/
2. **Run the companion server** — download below and run it
   (First run auto-configures everything and stays in the system tray)
3. **Tap "Find my PC" in the app** — it discovers the PC on the same Wi-Fi automatically

### Downloads

- **PC server (Microsoft Store, recommended)**: [Get it from the Microsoft Store](https://apps.microsoft.com/detail/9NT52T3RHR46)
  — signed, so no SmartScreen warning
- **PC server (GitHub)**: [latest release](https://github.com/sui-notes/Perforation-for-MPC/releases/latest)
  - `Perforation-Server-Setup-vX.X.X.exe` — installer
  - `Perforation-Server-vX.X.X-portable.zip` — portable (unzip and run)
- **Android app**: [Get it on Google Play](https://play.google.com/store/apps/details?id=jp.perforation)

### Requirements

- A Windows PC with MPC-HC or MPC-BE installed
- An Android phone
- Both on the same Wi-Fi network
