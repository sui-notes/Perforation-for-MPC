Perforation for MPC — 使い方ガイド

最終更新日: 2026年8月11日 ／ English version below

Perforation for MPC は、スマホ (Android) から PC の動画プレイヤー MPC-HC / MPC-BE を操作するリモコンです。スマホの「アプリ」と、PC 側の「サーバー」の 2 つで動きます。

セットアップ (3 ステップ)

  1. PC に MPC-HC (または MPC-BE) を入れる
    すでに使っているならそのままで OK。未導入なら MPC-HC (無料) をインストール。
  2. PC にサーバーを入れる
    Microsoft Store から入手 (推奨・セキュリティ警告なしで入ります)。 GitHub 派は 最新リリース から インストーラー版か、インストール不要のポータブル ZIP 版を選べます。 起動するとタスクトレイに常駐し、MPC の設定は自動で行われます。
    ※ Microsoft Store 版も準備中です。
  3. スマホにアプリ「Perforation for MPC」を入れる
    起動して「PC を自動検索」をタップすると、同じ Wi-Fi 上の PC が自動で見つかります。

動作要件

  • Windows 10 (1809) 以降 / 64bit
  • MPC-HC または MPC-BE (64bit)
  • Android 8.0 以降のスマホ
  • PC とスマホが同じネットワーク (Wi-Fi) に接続されていること

基本の使い方

  • プレイヤーは自動で立ち上がります: MPC を開いていなくても、アプリで再生を押すか ファイルをタップすれば、PC 側で MPC が自動起動してそのまま再生を始めます。 PC を操作しに行く必要はありません。うっかり MPC を閉じてしまっても、アプリを開けば復帰します。
  • メイン画面: 再生/一時停止・前後ファイル・±10 秒・停止・フルスクリーン・再生速度・コマ送り・音量を操作できます。
  • 音声・字幕の切替: 画面に表示されている音声/字幕の行をタップすると次のトラックに切り替わります。
  • ファイルブラウザ: 左上の ☰ から、PC 側で許可したフォルダを開いてタップ再生。対象フォルダは設定 (歯車) の「動画フォルダ (PC 側)」で増減できます。
  • 再生リスト: 画面最下部の「再生リスト n/m」をタップすると、再生中ファイルと同じフォルダの一覧から選べます。
  • チャプター: チャプター入りの動画では進捗バーの下に現在チャプターが表示されます。タップで一覧、◀ ▶ で前後ジャンプ (Pro)。

Pro 機能 (買い切り)

  • チャプター操作 — OP スキップや章ジャンプ
  • 連続再生 — ファイル末尾で自動的に次のファイルへ
  • ロック画面/通知での操作 — 画面を消したまま再生操作
  • Wake-on-LAN — スリープ中の PC をスマホから起こす（対応は PC の設定次第。下記参照）

トラブルシューティング

Q. 「PC が見つかりません」と出る
次を順に確認してください。
① PC とスマホが同じ Wi-Fi にいるか (ゲスト用 Wi-Fi や モバイル回線は不可)
② スマホ側の VPN アプリ (NordVPN 等) を一時オフにする。VPN が検索の通信を遮ることがあります (VPN の設定で「ローカルネットワークの探索を許可」でも可)
③ PC 側の初回起動時に Windows ファイアウォールの許可ダイアログが出たら「許可」
④ それでも見つからない場合、アプリはネットワーク全体を数十秒かけてスキャンします。少し待ってから再試行してください。
Q. チャプターが表示されない
チャプター情報の読み取りには ffprobe (FFmpeg 付属) が必要です。PC のコマンドプロンプトで winget install Gyan.FFmpeg を実行してから PC を再起動してください。 ffprobe が無くても他の機能は正常に動きます (チャプター行が出ないだけ)。
Q. Wake-on-LAN で PC が起きない
この機能はスリープ／休止状態からの復帰を想定しています。完全に電源を切った状態 (シャットダウン) からの起動は、多くの PC で動作しません。
スリープからでも起きない場合は、PC 側の BIOS/UEFI と LAN アダプタの設定で WOL を有効化 してください (「Wake on LAN」「PME をオンにする」等。メーカーにより名称が異なります)。 Windows の「高速スタートアップ」が有効だと妨げになることがあります。有線 LAN 接続の PC を推奨します。
なお、ハードウェアや設定によってはどうしても動作しない場合があります。 その場合でも他の機能はすべて通常どおり使えます。
Q. ダウンロード時に「WindowsによってPCが保護されました」と出る (SmartScreen)
GitHub 版はコード署名をしていないため表示されます。「詳細情報」→「実行」で起動できます。 この警告を避けたい場合は Microsoft Store 版 をお使いください (署名済み)。 配布物は本ページと同じ GitHub リポジトリと Microsoft Store からのみ提供しています。
Q. MPC は開いているのにリモコンが反応しない
サーバーより先に MPC を手動で起動していた場合、接続できないことがあります。 MPC をいったん閉じてから、アプリで再生操作をしてください (MPC が自動で立ち上がります)。

よくある質問

Q. 通信は安全?
通信は自宅の LAN 内で完結します。外部サーバーは存在せず、アカウント登録も不要、データ収集もありません。 詳細はプライバシーポリシーをご覧ください。
Q. 料金は?
アプリ・サーバーとも無料で、基本機能はすべて使えます。上記の Pro 4 機能のみ買い切りのアプリ内購入です。

Perforation for MPC — User Guide

Last updated: August 11, 2026

Perforation for MPC is an Android remote control for MPC-HC / MPC-BE on Windows. It consists of the phone app and a small PC server.

Setup (3 steps)

  1. Install MPC-HC (or MPC-BE) on your PC — if you already use it, skip this. Otherwise get MPC-HC (free).
  2. Install the PC server — get it from the Microsoft Store (recommended, installs without security warnings), or download the latest release from GitHub (installer or portable ZIP). It runs in the system tray and configures MPC automatically.
  3. Install the Android app "Perforation for MPC" — open it and tap Find my PC. Your PC is discovered automatically on the same Wi-Fi.

Requirements

  • Windows 10 (1809) or later, 64-bit
  • MPC-HC or MPC-BE (64-bit)
  • Android 8.0+
  • PC and phone on the same local network

Basics

  • The player starts itself: MPC doesn't have to be open. Hit play or tap a file in the app and MPC launches on the PC and starts playing — no need to walk over to the PC. Closed MPC by accident? Just open the app again and it comes back.
  • Main screen: play/pause, previous/next file, ±10s, stop, fullscreen, playback speed, frame step, volume.
  • Audio & subtitle tracks: tap the audio/subtitle rows to cycle tracks.
  • File browser: open ☰ (top left) to browse the folders you allowed on the PC and tap to play. Manage folders in Settings → "Video folders (PC)".
  • Playlist: tap the "Playlist n/m" bar at the bottom to pick from the current folder.
  • Chapters: for videos with chapters, the current chapter appears under the progress bar. Tap for the list, ◀ ▶ to jump (Pro).

Pro features (one-time purchase)

  • Chapter controls — skip openings, jump between chapters
  • Continuous playback — auto-advance to the next file
  • Lock screen / notification controls
  • Wake-on-LAN — wake a sleeping PC from your phone (depends on your PC's settings, see below)

Troubleshooting

Q. "PC not found"
Check in order:
① PC and phone are on the same Wi-Fi (guest Wi-Fi / mobile data won't work)
② Temporarily turn off VPN apps (NordVPN etc.) on the phone — VPNs can swallow discovery traffic (or allow "local network discovery" in the VPN settings)
③ If Windows Firewall asks about the server on first launch, click Allow
④ If still not found, the app also scans the whole network — wait a bit and retry.
Q. Chapters don't appear
Reading chapters requires ffprobe (part of FFmpeg). Run winget install Gyan.FFmpeg in Command Prompt, then restart the PC. Everything else works fine without it.
Q. Wake-on-LAN doesn't wake the PC
This feature is meant for waking a PC from sleep or hibernation. Starting a PC from a full shutdown does not work on most machines.
If it won't wake from sleep either, enable WOL in the PC's BIOS/UEFI and in the LAN adapter settings ("Wake on LAN", "Enable PME", names vary). Windows Fast Startup can also block it. A wired connection is recommended.
Depending on your hardware, it may simply not be supported — everything else still works.
Q. SmartScreen says "Windows protected your PC"
The GitHub build is not code-signed, so this warning appears. Click "More info" → "Run anyway". To avoid it entirely, use the Microsoft Store version (signed). Downloads are provided only from this GitHub repository and the Microsoft Store.
Q. MPC is open but the remote doesn't respond
If MPC was started manually before the server, it may not be controllable. Close MPC once, then start playback from the app (MPC relaunches automatically).

FAQ

Q. Is it safe?
All communication stays inside your local network. There is no external server, no account, and no data collection. See the privacy policy.
Q. Price?
The app and server are free with all core features. Only the four Pro features above are a one-time in-app purchase.
